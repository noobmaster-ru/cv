# cv

ATS-friendly резюме, LaTeX. Сборка: `make` (все варианты), `make clean` (убрать .aux/.log/.out).

```
ru/                       русские версии
  backend/  cv_ru_backend.tex   Python-разработчик          -> козлов_кирилл_python.pdf
  ml/       cv_ru_ml.tex        ML-разработчик              -> козлов_кирилл_мл.pdf
  fd/       cv_ru_fde.tex       Forward Deployed Engineer
eng/                      английские версии
  backend/  cv_eng_backend.tex  Python Backend Developer    -> kozlov_kirill_python.pdf
  ml/       cv_eng_ml.tex       Machine Learning Developer
            cv_eng_plata.tex    адресная: Plata, AI Engineer Middle/Middle+
  fd/       cv_eng_fde.tex      Forward Deployed Engineer
```

Каждый `.tex` самостоятелен; PDF лежит рядом с исходником.
